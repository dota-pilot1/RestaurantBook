# 판매 메뉴 카테고리별 메뉴 순서 조절 구현 계획

작성일: 2026-05-10

## 결론

카테고리 자체 순서 조절은 기존 `/sale-menu-categories`에서 처리한다.

`/sale-menus`에서는 카테고리 탭을 통해 특정 카테고리 메뉴만 출력하고, 그 상태에서 해당 카테고리 내부 메뉴 순서만 조절한다. 모든 메뉴를 한 번에 섞어서 정렬하는 기능은 MVP에서 제외한다.

## UX 결정

관리자 판매 메뉴 화면:

- 카드/테이블 토글이 있는 목록 툴바 왼쪽에 카테고리 탭을 둔다.
- 탭 라벨은 `전체 (15)`, `식사 (3)`, `국/찌개 (3)`처럼 카운트를 포함한다.
- `전체`에서는 카테고리 순서와 메뉴 순서를 기준으로 읽기만 한다.
- 특정 카테고리 탭을 선택하면 해당 카테고리 메뉴만 출력한다.
- 특정 카테고리 선택 + 검색/상태/노출 추가 필터가 없는 상태에서만 DnD 순서 조절을 허용한다.
- 판매 메뉴 수정폼에서는 `정렬 순서` 입력을 제거한다.
- 판매 메뉴 수정 다이얼로그 우상단에 닫기 버튼을 추가한다.

고객 키오스크 후속:

- 기본 선택은 첫 번째 실제 카테고리로 둔다.
- 카테고리 버튼 마지막에 `전체 보기`를 추가한다.
- `전체 보기`는 카테고리 순서대로 섹션을 만들고, 각 섹션 안에 해당 메뉴를 보여준다.
- flat list로 모든 메뉴를 섞어 출력하지 않는다.

## 완료 기준

- 판매 메뉴 목록 툴바 왼쪽에 카테고리 탭이 표시된다.
- 카테고리 탭 선택 시 해당 카테고리 메뉴만 표시된다.
- 특정 카테고리 메뉴 목록에서 DnD로 메뉴 순서를 저장할 수 있다.
- 카테고리 자체 순서 조절은 `/sale-menu-categories`에만 남긴다.
- 판매 메뉴 수정폼에는 숫자형 `정렬 순서` 입력이 노출되지 않는다.
- 수정 다이얼로그 우상단 닫기 버튼이 동작한다.
