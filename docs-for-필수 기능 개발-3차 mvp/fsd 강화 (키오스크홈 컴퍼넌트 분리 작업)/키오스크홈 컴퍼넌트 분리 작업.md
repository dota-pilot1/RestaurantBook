# 키오스크홈 컴퍼넌트 분리 작업

작성일: 2026-05-10

## 왜 분리 했나?

기존 `KioskHome.tsx`는 약 3천 줄 규모의 단일 파일이었다.

한 파일 안에 아래 책임이 모두 섞여 있었다.

- 고객 키오스크 라우트 진입 컴포넌트
- 주문/취소/직원 호출/결제/설정 상태 관리
- TanStack Query 조회와 mutation
- WebSocket 수신 처리
- 장바구니 계산
- 결제 가능 주문 선택 로직
- 모바일 메뉴 카드 pager 로직
- 데스크톱/모바일 화면 JSX
- 다이얼로그와 요약 UI
- 가격/시간 포맷, 탭 key, cart key 같은 순수 helper

이 상태에서는 작은 UI 수정도 주문/결제 상태 로직과 같은 파일을 건드리게 된다. 그래서 FSD 기준에 맞춰 책임을 나눴다.

분리 기준은 다음과 같다.

- `model`: 키오스크 기능의 상태 모델, 타입, 상수, custom hook
- `lib`: React와 무관한 순수 helper
- `ui`: 화면 컴포넌트
- `KioskHome.tsx`: `useKioskOrder()`를 호출하고 모바일/데스크톱 뷰를 선택하는 조립 파일

이번 작업에서는 `hooks/` 폴더를 따로 만들지 않았다. FSD 관점에서 `useKioskOrder`, `useMobileProductPager`는 단순 API wrapper가 아니라 키오스크 feature의 상태 모델이므로 `model/`에 두는 편이 더 적절하다고 판단했다.

### `KioskHome.tsx`

역할:

- `useKioskOrder()` 호출
- `variant`에 따라 `KioskMobileView` 또는 `KioskDesktopView` 렌더링

현재 구조:

```tsx
export function KioskHome({ variant = "desktop" }: { variant?: "desktop" | "mobile" }) {
  const kiosk = useKioskOrder();

  if (variant === "mobile") {
    return <KioskMobileView kiosk={kiosk} />;
  }

  return <KioskDesktopView kiosk={kiosk} />;
}
```

### `model/useKioskOrder.ts`

역할:

- 키오스크의 주 상태 모델
- 카테고리/상품/주문/직원 호출/결제/설정 query와 mutation 관리
- WebSocket 수신 처리
- 장바구니, 결제 선택, 주문 접수, 호출 생성/취소, 설정 저장 handler 제공

이 파일은 아직 큰 orchestration hook이다. 이후 더 줄이려면 아래 단위로 추가 분리할 수 있다.

- `useKioskTabs`
- `useKioskCart`
- `useKioskOrders`
- `useKioskPayments`
- `useKioskStaffCalls`
- `useKioskSettings`
- `useCancelNotices`

### `model/useMobileProductPager.ts`

역할:

- 모바일 키오스크 메뉴 카드 pager 상태
- 현재 카드 index
- slide 방향
- touch swipe 시작/종료 처리

모바일 화면 전용 상태라 `KioskMobileView`에서 분리했다.

### `model/types.ts`

역할:

- `KioskOrderType`
- `PaymentSelectionMode`
- `KioskTab`
- `CartItemKey`
- `CartItem`
- `CancelNotice`
- `CancelNoticeItem`

### `model/constants.ts`

역할:

- `SET_TAB`
- `ALL_TAB`
- `CUSTOMER_ORDER_REFETCH_INTERVAL_MS`
- `TOSS_PAYMENT_META_KEY_PREFIX`
- 주문 상태 label/class
- 직원 호출 타입 label
- 역할별 결제 안내 문구

### `lib/*`

React와 무관한 순수 helper만 둔다.

| 파일 | 역할 |
| --- | --- |
| `lib/cart.ts` | cart key 생성 |
| `lib/format.ts` | 가격/시간/테이블 배지 포맷 |
| `lib/order.ts` | 주문 수량 계산 |
| `lib/tab.ts` | 탭 활성 여부, 탭 key 생성 |
| `lib/cancelNotice.ts` | 취소 안내 item 변환/병합, 취소 알림음 |

### `ui/*`

화면 렌더링 컴포넌트만 둔다.

| 파일 | 역할 |
| --- | --- |
| `ui/KioskDesktopView.tsx` | 데스크톱/태블릿 키오스크 화면 |

| `ui/KioskDialogs.tsx` | 모바일에서 공유하는 주문/결제/호출/설정 다이얼로그 |

| `ui/OrderTypeButton.tsx` | 매장/포장 버튼 |
| `ui/PaymentModePicker.tsx` | 단건/다건 결제 방식 선택 |
| `ui/PaymentReadySummary.tsx` | 결제 대상 주문 선택/요약 |
| `ui/AcceptedOrdersSummary.tsx` | 접수된 주문 목록 |
| `ui/OrderHistoryItem.tsx` | 주문 item 표시 |
| `ui/OrderSummaries.tsx` | 주문 접수/완료/취소 요약 |
| `ui/QuantityButton.tsx` | 수량 증감 버튼 |

## 후속 분리 후보

이번 작업은 파일 크기와 책임 분리를 먼저 해결한 1차 FSD 정리다.

다음 단계에서는 `model/useKioskOrder.ts`를 아래처럼 더 쪼개는 것이 좋다.

```text
model/
  useKioskOrder.ts        # 조립 hook
  useKioskTabs.ts         # 카테고리/탭/상품 조회
  useKioskCart.ts         # 장바구니 상태와 수량 계산
  useKioskOrders.ts       # 주문 조회/생성/취소
  useKioskPayments.ts     # 결제 가능 주문, 선택 결제, 토스 실행
  useKioskStaffCalls.ts   # 직원 호출 조회/생성/취소
  useKioskSettings.ts     # 로그인바 설정
  useCancelNotices.ts     # 취소 WebSocket 안내/ack 처리
```

이후에는 `KioskDesktopView.tsx` 안에 남아 있는 일부 다이얼로그 중복도 `KioskDialogs.tsx`와 더 통합할 수 있다.
