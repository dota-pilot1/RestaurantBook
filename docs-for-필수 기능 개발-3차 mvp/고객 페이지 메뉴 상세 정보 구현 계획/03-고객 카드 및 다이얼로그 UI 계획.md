# 03. 고객 카드 및 다이얼로그 UI 계획

## 카드 변경

### `restaurant-book-front/src/features/kiosk/ui/MenuCard.tsx`

현재 `MenuCard`는 카드 전체가 `role="button"`이고 클릭 시 선택 토글을 실행한다. 따라서 정보 버튼은 반드시 이벤트 전파를 막아야 한다.

추가 prop:

```ts
onOpenDetail: () => void;
```

아이콘 import:

```ts
import { Check, ImageIcon, Info, Minus, Plus } from "lucide-react";
```

렌더링 규칙:

- `quantity === 0`일 때만 정보 버튼 표시
- `quantity > 0`일 때는 기존 체크 표시만 표시
- `soldOut` 배지는 정보 버튼과 겹치지 않도록 좌상단 배치

정보 버튼 예시:

```tsx
{quantity === 0 && (
  <button
    type="button"
    aria-label={`${product.name} 상세 정보 보기`}
    onClick={(event) => {
      event.preventDefault();
      event.stopPropagation();
      onOpenDetail();
    }}
    className="absolute right-2 top-2 z-30 flex h-8 w-8 items-center justify-center rounded-full border border-white/70 bg-white/95 text-zinc-900 shadow-md hover:bg-white focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring"
  >
    <Info className="h-4 w-4" />
  </button>
)}
```

품절 배지 위치 변경:

```tsx
<span className="absolute left-3 top-3 ...">품절</span>
```

## 상세 상태 추가

### `restaurant-book-front/src/features/kiosk/model/useKioskOrder.ts`

상태 추가:

```ts
const [detailProduct, setDetailProduct] = useState<CustomerSaleProduct | null>(null);
```

반환값 추가:

```ts
detailProduct,
setDetailProduct,
```

이벤트 명은 뷰에서 명확하게 쓰기 위해 아래처럼 써도 된다.

```ts
const openProductDetail = (product: CustomerSaleProduct) => setDetailProduct(product);
const closeProductDetail = () => setDetailProduct(null);
```

반환:

```ts
openProductDetail,
closeProductDetail,
```

## 모바일 연결

### `restaurant-book-front/src/features/kiosk/ui/KioskMobileView.tsx`

`kiosk` destructuring에 추가:

```ts
openProductDetail,
```

활성 카드에 추가:


모바일 카드의 좌우 이동 버튼과 겹치지 않는지 확인한다. 정보 버튼은 카드 내부 이미지 우상단이라 현재 좌우 이동 버튼과 직접 충돌하지 않는다.

## 다이얼로그 컴포넌트

권장 파일:

### `restaurant-book-front/src/features/kiosk/ui/MenuDetailDialog.tsx`

새 컴포넌트로 분리한다.

props:

```ts
type Props = {
  product: CustomerSaleProduct | null;
  onClose: () => void;
};
```

레이아웃:

- `product === null`이면 `null` 반환
- overlay: `fixed inset-0 z-50`
- dialog: `max-w-4xl`
- desktop: `grid md:grid-cols-[minmax(0,1.2fr)_minmax(280px,0.8fr)]`
- mobile: 단일 컬럼

왼쪽 정보:

- 이미지
- 메뉴명, 가격
- 짧은 설명
- 상세 설명
- 세트 구성 `components`
- 원재료
- 알레르기 정보

오른쪽 영양:

- 열량 kcal
- 탄수화물 g
- 단백질 g
- 지방 g
- 나트륨 mg

빈 상태:

- 상세 정보가 모두 없으면 `등록된 상세 정보가 없습니다.`
- 영양 정보가 모두 없으면 `등록된 영양 정보가 없습니다.`

## 접근성/이벤트 체크

- `Info` 버튼은 `button`이어야 한다.
- 카드 내부 버튼 클릭 시 카드 선택이 토글되지 않아야 한다.
- 다이얼로그는 `role="dialog"`와 `aria-modal="true"`를 가진다.
- 닫기 버튼은 `aria-label="닫기"`를 가진다.
- Esc 닫기까지 필요하면 `useEffect`로 keydown을 붙인다.

## UI 완료 기준

- 선택 전 카드 우상단에 `i` 버튼이 보인다.
- `i` 버튼 클릭 시 장바구니에 담기지 않고 다이얼로그만 열린다.
- 선택 후 카드 우상단에는 체크만 보인다.
- 품절 배지와 `i` 버튼이 겹치지 않는다.
- 데스크톱 다이얼로그는 좌우 2열이다.
- 모바일 다이얼로그는 세로 1열이다.
