## 7단계: 검증

백엔드:

```txt
./gradlew compileJava
```

프론트:

```txt
npm run lint
npm run build
```

수동 확인:

```txt
/sale-menus
/sale-menu-categories
/sale-menu-availability
```

확인 항목:

- 관리자만 접근 가능
- 목록이 비어도 빈 상태가 자연스럽다
- 생성 후 목록이 갱신된다
- 수정 후 목록이 갱신된다
- 삭제 후 목록이 갱신된다
- 이미지 업로드 실패 시 오류가 보인다
- 가격 표시가 깨지지 않는다
- 긴 메뉴명이 레이아웃을 깨지 않는다
