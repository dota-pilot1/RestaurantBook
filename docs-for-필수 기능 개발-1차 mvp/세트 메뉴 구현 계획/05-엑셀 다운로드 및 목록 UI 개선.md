# 05. 세트 메뉴 엑셀 다운로드 및 목록 UI 개선

작성일: 2026-05-09

## 결론

세트 메뉴는 단품 판매 메뉴보다 엑셀 다운로드 설계가 더 까다롭다. 이유는 세트 1개가 여러 구성 품목을 가지는 1:N 구조이기 때문이다.

따라서 MVP는 백엔드 Excel API를 만들지 않고, 현재 `/sale-menu-sets` 화면에서 이미 조회한 `sortedSets` 데이터로 프론트에서 `.xlsx`를 생성한다. 단, 단품 메뉴처럼 한 시트만 만들면 구성 품목 정보가 뭉개지므로 workbook은 다음 2개 시트로 나눈다.

| 시트 | 기준 | 목적 |
|---|---|---|
| `세트 목록` | 세트 1개 = 1행 | 운영자가 세트 상품 단위로 가격/상태/노출을 검토 |
| `구성 품목` | 구성 품목 1개 = 1행 | 세트별 단품 구성과 수량을 정확히 검토 |

엑셀 업로드는 제외한다. 세트 업로드는 단품 메뉴 ID 매칭, 구성 중복 검증, 수량 검증, 순서 검증, 트랜잭션 롤백까지 필요해서 다운로드보다 훨씬 크다.

## 목록 UI 개선

### 문제

현재 구성 컬럼은 아래처럼 한 줄 텍스트로 출력된다.

```tsx
<p className="max-w-[280px] truncate text-xs text-muted-foreground">
  {set.items.map((item) => `${item.saleMenu.name} x${item.quantity}`).join(", ") || "-"}
</p>
```

문제점:

- 구성 품목이 3개 이상이면 대부분 잘린다.
- `text-muted-foreground`라 주요 정보치고 너무 흐릿하다.
- 품목명과 수량이 한 문자열에 섞여 스캔이 어렵다.
- 세트 메뉴의 핵심 정보가 가격/상태보다 덜 보인다.

### 권장 UX

구성 컬럼은 세로 배지 리스트로 바꾼다.

```txt
육회 비빔밥        x1
오늘의 반찬        x1
식혜              x1
```

또는 compact badge:

```txt
[육회 비빔밥] [x1]
[오늘의 반찬] [x1]
[식혜]       [x1]
```

추천은 세로형이다. 표에서 가로 공간은 넓지만 구성 문자열은 길어서 잘리기 쉽고, 세로 배지는 품목 단위 비교가 빨라진다.

### 구현 방식

`SaleMenuSetTable.tsx`에 작은 컴포넌트를 추가한다.

```tsx
function SetItemBadges({ items }: { items: SaleMenuSet["items"] }) {
  const visibleItems = items.slice(0, 4);
  const hiddenCount = Math.max(0, items.length - visibleItems.length);

  if (items.length === 0) {
    return <span className="text-xs text-muted-foreground">-</span>;
  }

  return (
    <div className="flex max-w-[320px] flex-col gap-1">
      {visibleItems.map((item) => (
        <span
          key={item.id}
          className="inline-flex w-fit max-w-full items-center gap-1.5 rounded-md border border-border bg-muted/45 px-2 py-1 text-xs text-foreground"
        >
          <span className="truncate">{item.saleMenu.name}</span>
          <span className="shrink-0 rounded bg-background px-1.5 py-0.5 font-semibold text-muted-foreground">
            x{item.quantity}
          </span>
        </span>
      ))}
      {hiddenCount > 0 && (
        <span className="w-fit rounded-md border border-dashed border-border px-2 py-1 text-xs text-muted-foreground">
          +{hiddenCount}개 더 있음
        </span>
      )}
    </div>
  );
}
```

기존 구성 컬럼 교체:

```tsx
<Td>
  <SetItemBadges items={set.items} />
</Td>
```

테이블 최소 너비는 현재 `min-w-[980px]`인데, 구성 컬럼 가독성을 위해 `min-w-[1080px]` 정도로 늘리는 것을 권장한다.

## 엑셀 row 설계

### `세트 목록` 시트

세트 1개당 1행이다.

| 컬럼 | 값 |
|---|---|
| ID | `set.id` |
| 세트명 | `set.name` |
| 설명 | `set.description ?? ""` |
| 가격 | `set.price` |
| 판매 상태 | `ACTIVE=판매중`, `SOLD_OUT=품절`, `HIDDEN=숨김` |
| 고객 노출 | `visible ? "노출" : "숨김"` |
| 매장 주문 | `availableDineIn ? "가능" : "불가"` |
| 포장 주문 | `availableTakeout ? "가능" : "불가"` |
| 정렬 순서 | `set.displayOrder` |
| 구성 품목 수 | `set.items.length` |
| 구성 요약 | `육회 비빔밥 x1, 오늘의 반찬 x1, 식혜 x1` |
| 이미지 URL | `set.imageUrl ?? ""` |
| 생성일 | `set.createdAt` |
| 수정일 | `set.updatedAt` |

### `구성 품목` 시트

구성 품목 1개당 1행이다.

| 컬럼 | 값 |
|---|---|
| 세트 ID | `set.id` |
| 세트명 | `set.name` |
| 세트 가격 | `set.price` |
| 구성 순서 | `item.displayOrder` |
| 단품 메뉴 ID | `item.saleMenu.id` |
| 단품 메뉴명 | `item.saleMenu.name` |
| 단품 가격 | `item.saleMenu.price` |
| 세트 1개당 수량 | `item.quantity` |
| 구성 금액 참고 | `item.saleMenu.price * item.quantity` |

`구성 금액 참고`는 세트 가격 계산에 쓰는 값이 아니라 검토용이다. 세트 가격은 독립 가격이므로 구성 합계와 다를 수 있다.

## 구현 함수 계획

상태:


라벨 helper:

```ts
const STATUS_LABEL = {
  ACTIVE: "판매중",
  SOLD_OUT: "품절",
  HIDDEN: "숨김",
} as const;

function yesNo(value: boolean, yes = "가능", no = "불가") {
  return value ? yes : no;
}

function formatDateForFileName(date = new Date()) {
  const pad = (value: number) => String(value).padStart(2, "0");
  return [
    date.getFullYear(),
    pad(date.getMonth() + 1),
    pad(date.getDate()),
    "_",
    pad(date.getHours()),
    pad(date.getMinutes()),
  ].join("");
}
```

다운로드 handler:

```ts
async function handleDownloadExcel() {
  if (sortedSets.length === 0 || isDownloadingExcel) return;

  try {
    setIsDownloadingExcel(true);
    const XLSX = await import("xlsx");

    const setRows = sortedSets.map((set) => ({
      ID: set.id,
      세트명: set.name,
      설명: set.description ?? "",
      가격: set.price,
      "판매 상태": STATUS_LABEL[set.status],
      "고객 노출": set.visible ? "노출" : "숨김",
      "매장 주문": yesNo(set.availableDineIn),
      "포장 주문": yesNo(set.availableTakeout),
      "정렬 순서": set.displayOrder,
      "구성 품목 수": set.items.length,
      "구성 요약": set.items
        .map((item) => `${item.saleMenu.name} x${item.quantity}`)
        .join(", "),
      "이미지 URL": set.imageUrl ?? "",
      생성일: set.createdAt,
      수정일: set.updatedAt,
    }));

    const itemRows = sortedSets.flatMap((set) =>
      set.items.map((item) => ({
        "세트 ID": set.id,
        세트명: set.name,
        "세트 가격": set.price,
        "구성 순서": item.displayOrder,
        "단품 메뉴 ID": item.saleMenu.id,
        "단품 메뉴명": item.saleMenu.name,
        "단품 가격": item.saleMenu.price,
        "세트 1개당 수량": item.quantity,
        "구성 금액 참고": item.saleMenu.price * item.quantity,
      })),
    );

    const workbook = XLSX.utils.book_new();
    const setSheet = XLSX.utils.json_to_sheet(setRows);
    const itemSheet = XLSX.utils.json_to_sheet(itemRows);

    setSheet["!cols"] = [
      { wch: 8 },
      { wch: 24 },
      { wch: 36 },
      { wch: 12 },
      { wch: 12 },
      { wch: 10 },
      { wch: 10 },
      { wch: 10 },
      { wch: 10 },
      { wch: 12 },
      { wch: 60 },
      { wch: 40 },
      { wch: 22 },
      { wch: 22 },
    ];

    itemSheet["!cols"] = [
      { wch: 10 },
      { wch: 24 },
      { wch: 12 },
      { wch: 10 },
      { wch: 12 },
      { wch: 24 },
      { wch: 12 },
      { wch: 14 },
      { wch: 14 },
    ];

    XLSX.utils.book_append_sheet(workbook, setSheet, "세트 목록");
    XLSX.utils.book_append_sheet(workbook, itemSheet, "구성 품목");
    XLSX.writeFile(workbook, `세트메뉴_${formatDateForFileName()}.xlsx`);
    toast.success("세트 메뉴 엑셀 파일을 다운로드했습니다.");
  } catch (error) {
    toastError(error, "엑셀 다운로드에 실패했습니다.");
  } finally {
    setIsDownloadingExcel(false);
  }
}
```

## 완료 기준

- 세트 목록의 구성 컬럼이 흐릿한 한 줄 텍스트가 아니라 세로 배지 리스트로 표시된다.
- 관리자가 현재 필터 기준 세트 메뉴를 `.xlsx`로 다운로드할 수 있다.
- 엑셀 파일은 세트 단위 요약과 구성 품목 단위 상세를 분리해서 제공한다.
- 엑셀 업로드 기능은 노출하지 않는다.
- 기존 세트 추가/수정/삭제, 빠른 상태 변경, 노출 토글에 회귀가 없다.
