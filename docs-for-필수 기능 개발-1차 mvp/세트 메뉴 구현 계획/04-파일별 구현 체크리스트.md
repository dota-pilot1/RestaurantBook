## 9단계: 세트 목록 가독성 개선 + 엑셀 다운로드

신규 문서:

- `docs-for-필수 기능 개발-1차 mvp/세트 메뉴 구현 계획/05-엑셀 다운로드 및 목록 UI 개선.md`

수정 파일:

- `restaurant-book-front/package.json`
- `restaurant-book-front/package-lock.json`
- `restaurant-book-front/src/features/sale-menu-set-management/SaleMenuSetManagement.tsx`
- `restaurant-book-front/src/features/sale-menu-set-management/SaleMenuSetTable.tsx`

체크:

- 구성 컬럼은 한 줄 truncate 텍스트 대신 세로 배지 리스트로 표시
- 구성 품목명과 수량이 명확히 분리되어 보임
- 구성 품목이 많은 경우 첫 3~4개만 표시하고 `+N` 배지로 접음
- `엑셀 다운로드` 버튼은 `/sale-menu-sets` 상단 액션 영역에 추가
- 다운로드 대상은 현재 필터와 정렬이 적용된 `sortedSets`
- Excel workbook은 `세트 목록`, `구성 품목` 2개 시트로 구성
- 엑셀 업로드는 범위에서 제외
