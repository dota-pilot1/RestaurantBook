# 파일별 구현 체크리스트

## 1단계: 백엔드 주문 enum 추가

신규:

- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/OrderType.java`
- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/OrderStatus.java`
- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/OrderItemType.java`

체크:

- `OrderType`: `DINE_IN`, `TAKEOUT`
- `OrderStatus`: MVP는 `RECEIVED`
- `OrderItemType`: `SALE_MENU`, `SALE_MENU_SET`
- 고객 상품의 `SaleProductType`과 문자열 값이 일치해야 함

## 2단계: 백엔드 주문 엔티티 추가

신규:

- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/Order.java`
- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/OrderItem.java`
- `restaurant-book-server/src/main/java/com/cj/restaurantbook/order/domain/OrderItemComponent.java`

체크:

- `Order`와 `OrderItem`은 `@OneToMany(cascade = CascadeType.ALL, orphanRemoval = true)`
- `OrderItem`과 `OrderItemComponent`도 cascade 저장
- `Order.addItem` 또는 생성 메서드에서 양방향 관계 세팅
- `lineTotal = unitPrice * quantity`
- `totalAmount = sum(lineTotal)`
- 세트 구성은 주문 당시 스냅샷으로 저장

## 11단계: 검증

명령:

```txt
restaurant-book-server: ./gradlew test
restaurant-book-front: npm run build
```

수동 시나리오:

- 세트 2개를 담고 주문 접수
- 단품 1개와 세트 1개를 같이 담고 주문 접수
- 품절 상품은 카드에서 추가 불가
- 주문 직전 품절로 바뀐 상품은 서버에서 거절
- 포장 불가 상품을 포장 주문으로 저장하려 하면 서버에서 거절

DB 확인:

```txt
orders 1행 생성
order_items 상품 수만큼 생성
세트 order_item에 order_item_components 생성
total_amount가 order_items line_total 합계와 일치
```
