
## 판매 상태 enum

```txt
SaleMenuStatus

ACTIVE
SOLD_OUT
HIDDEN
```

의미:

- `ACTIVE`: 판매 가능
- `SOLD_OUT`: 품절 표시
- `HIDDEN`: 고객 키오스크에서 숨김

`visible`과 `status`가 겹쳐 보일 수 있으나 MVP에서는 아래처럼 쓴다.

- `visible`: 운영자가 노출 자체를 끄는 스위치
- `status`: 판매 업무 상태

키오스크 노출 조건:

```txt
visible = true
status in (ACTIVE, SOLD_OUT)
주문 유형에 따라 available_dine_in 또는 available_takeout = true
```

주문 가능 조건:

```txt
visible = true
status = ACTIVE
주문 유형에 따라 available_dine_in 또는 available_takeout = true
```

## 검증 규칙

카테고리:

- `name` 필수
- `name` 최대 100자
- `displayOrder`는 0 이상 권장

판매 메뉴:

- `name` 필수
- `price`는 0 이상
- `description` 최대 500자
- `imageUrl` 최대 1024자
- `categoryId`는 null 허용
- `status`는 enum 값만 허용

## 삭제 정책

MVP에서는 물리 삭제로 시작한다.

다만 주문 연동이 붙은 뒤에는 판매 메뉴를 물리 삭제하면 과거 주문 상세가 깨질 수 있다.

주문 연동 이후 권장 정책:

- 판매 메뉴 삭제 대신 `HIDDEN` 처리
- 주문에 연결된 판매 메뉴는 삭제 금지
- 과거 주문에는 주문 당시 메뉴명/가격 스냅샷 저장
