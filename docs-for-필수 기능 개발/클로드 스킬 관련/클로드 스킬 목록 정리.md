## beauty-book-deploy

- **호출**: `/beauty-book-deploy` 또는 "배포해줘", "프론트 배포", "백엔드 배포", "운영 반영" 등
- **용도**: BeautyBook(dxline-tallent.com) 프론트/백엔드 배포 자동화
- **동작**:
  1. 프론트·백엔드·둘 다 중 배포 대상 확인
  2. `배포 가이드/*.md` 참고해서 검증된 스크립트 실행
  3. 프론트: `.env.local` 임시 백업 → 빌드 → S3 sync (`--exclude "beauty-book/*"`) → CloudFront 무효화 → `.env.local` 복구
  4. 백엔드: Gradle 빌드 → SCP 전송 → systemd 재시작 (nohup 절대 금지) → sleep 45s → 기동 확인
  5. 배포 후 체크리스트 실행 (영업시간, 근무 스케줄 확인 포함)
- **스킬 파일**: `~/.claude/skills/beauty-book-deploy/SKILL.md`
