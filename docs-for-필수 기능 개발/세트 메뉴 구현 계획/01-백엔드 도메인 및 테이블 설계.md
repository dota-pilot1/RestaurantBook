# 백엔드 도메인 및 테이블 설계

## 패키지 구조

세트 메뉴는 단품 판매 메뉴와 구분되는 주문 상품이므로 별도 패키지를 둔다.

```txt
restaurant-book-server/src/main/java/com/cj/restaurantbook/sale_menu_set
├── application
├── domain
├── infrastructure
└── presentation
    └── dto
```

단품 메뉴는 기존 패키지를 유지한다.

```txt
restaurant-book-server/src/main/java/com/cj/restaurantbook/sale_menu
```

## sale_menu_sets

주문 가능한 세트 상품 테이블.

```txt
id bigint pk
name varchar(100) not null
description varchar(500) null
price integer not null
image_url varchar(1024) null
status varchar(30) not null
visible boolean not null default true
available_dine_in boolean not null default true
available_takeout boolean not null default true
display_order int not null default 0
created_at timestamptz not null
updated_at timestamptz not null
```

권장 엔티티:

```txt
SaleMenuSet
```

권장 Repository:

```txt
SaleMenuSetRepository
```

상태 enum은 기존 `SaleMenuStatus`를 재사용해도 된다.

## sale_menu_set_items

세트에 포함되는 단품 판매 메뉴 구성 테이블.

```txt
id bigint pk
sale_menu_set_id bigint fk sale_menu_sets.id not null
sale_menu_id bigint fk sale_menus.id not null
quantity int not null default 1
display_order int not null default 0
created_at timestamptz not null
updated_at timestamptz not null
```

권장 엔티티:

```txt
SaleMenuSetItem
```

권장 Repository:

```txt
SaleMenuSetItemRepository
```

관계:

```txt
SaleMenuSet 1 --- N SaleMenuSetItem
SaleMenuSetItem N --- 1 SaleMenu
```

## 카테고리 관계

`세트`는 카테고리로 강제하지 않는다.

카테고리는 단품 메뉴 분류다.

```txt
식사
국/찌개
반찬
음료
```

세트 화면의 `세트` 탭은 `sale_menu_sets` 목록을 보여주는 UI 탭이다. 운영상 세트도 분류가 필요해지면 나중에 `sale_menu_set_categories`를 별도로 검토한다.

## 도메인 규칙

세트 메뉴:

- 이름 필수
- 가격 0 이상
- 구성 품목 최소 1개 이상
- 구성 품목 수량 1 이상
- 구성 품목은 기존 `sale_menus`만 참조
- 같은 세트 안에서 같은 `saleMenuId` 중복은 금지하거나 수량 합산

단품 메뉴:

- 기존 `sale_menus` 도메인을 유지
- 세트 구성 여부와 무관하게 독립 판매 가능

## 주문 스냅샷

주문 도메인에는 단품/세트 구분이 필요하다.

```txt
order_items
id bigint pk
order_id bigint fk orders.id not null
item_type varchar(30) not null
sale_menu_id bigint null
sale_menu_set_id bigint null
item_name varchar(100) not null
unit_price integer not null
quantity int not null
line_total integer not null
```

`item_type`:

```txt
SALE_MENU
SALE_MENU_SET
```

세트 구성 스냅샷:

```txt
order_item_components
id bigint pk
order_item_id bigint fk order_items.id not null
sale_menu_id bigint null
component_name varchar(100) not null
quantity int not null
display_order int not null
```

중요한 점:

- 주문 생성 시 서버가 현재 `sale_menu_sets`, `sale_menu_set_items`, `sale_menus`를 조회한다.
- 프론트에서 보낸 가격/구성은 신뢰하지 않는다.
- 주문 후 세트명이나 구성이 바뀌어도 과거 주문은 스냅샷으로 보여준다.
