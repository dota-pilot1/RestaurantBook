# 개발 환경 설정 가이드

> 프로젝트를 처음 받아서 로컬에서 실행하기까지의 전체 절차입니다.

---

## 사전 설치 요구사항

| 도구 | 버전 | 비고 |
|------|------|------|
| **Java (JDK)** | 21 | `java -version` 으로 확인 |
| **Node.js** | 20 이상 | `node -v` 으로 확인 |
| **Docker Desktop** | 최신 | PostgreSQL 컨테이너 실행용 |
| **Git** | 최신 | |

---

## 1. 저장소 클론

```bash
git clone <저장소 URL>
cd RestaurantBook
```

---

## 2. 데이터베이스 실행 (Docker)

프로젝트 루트에 있는 `docker-compose.yml`을 사용해 PostgreSQL을 실행합니다.

```bash
docker compose up -d
```

### 생성되는 컨테이너 정보

| 항목 | 값 |
|------|----|
| 컨테이너명 | `restaurant-book-postgres` |
| 이미지 | `postgres:15-alpine` |
| 호스트 포트 | **5435** (로컬) → 5432 (컨테이너) |
| DB명 | `restaurant_book` |
| 유저 / 비밀번호 | `postgres` / `postgres` |

```bash
# 정상 기동 확인
docker compose ps
```

## 3. 백엔드 설정 (`restaurant-book-server`)

### 3-1. `application-local.yaml` 생성

`application-local.yaml.example`을 복사해 실제 파일을 만듭니다.

```bash
cp restaurant-book-server/src/main/resources/application-local.yaml.example \
   restaurant-book-server/src/main/resources/application-local.yaml
```

### 3-2. 로컬 개발용 최소 설정

아래 내용이 기본으로 들어 있습니다. **로컬 개발 시에는 그대로 사용 가능**합니다.

```yaml
# application-local.yaml

# 이메일 인증: 실제 발송 없이 서버 로그에 인증코드 출력
auth:
  email-verification:
    log-only: true          # 로그에서 6자리 코드 확인
    dev-bypass-code: "1234" # 이 코드로 인증 우회 가능

# AWS S3 (이미지 업로드 기능을 쓰지 않는다면 빈 값으로 두어도 됨)
aws:
  s3:
    access-key: YOUR_AWS_ACCESS_KEY_ID
    secret-key: YOUR_AWS_SECRET_ACCESS_KEY
    bucket: your-bucket-name
    region: ap-northeast-2
    prefix: restaurant-book
```

> **실제 Gmail SMTP를 테스트하려면** `log-only: false`로 변경하고  
> `MAIL_USERNAME` / `MAIL_PASSWORD` 환경변수를 설정하거나  
> `application-local.yaml`에 직접 Gmail 계정 정보를 입력하세요.

### 3-3. 서버 실행

```bash
cd restaurant-book-server
./gradlew bootRun
```

- 실행 포트: **4201**
- Swagger UI: [http://localhost:4201/swagger-ui/index.html](http://localhost:4201/swagger-ui/index.html)

> **시드 데이터**: 서버가 처음 실행되면 테스트 계정, 샘플 메뉴 데이터가 자동으로 생성됩니다.  
> 기본 비밀번호는 `password123`, 이메일 도메인은 `restaurantbook.local`입니다.

## 4. 프론트엔드 설정 (`restaurant-book-front`)

### 4-1. 의존성 설치

```bash
cd restaurant-book-front
npm install
```

### 4-2. 환경변수 파일 생성

`env.example.txt`를 참고해 `.env.local`을 만듭니다.

```bash
cp restaurant-book-front/env.example.txt restaurant-book-front/.env.local
```

`.env.local` 기본 내용:

```env
# 백엔드 API 주소 (로컬 서버 포트와 일치해야 함)
NEXT_PUBLIC_API_URL=http://localhost:4201

# 테스트 계정 빠른 로그인 버튼 표시 여부
NEXT_PUBLIC_ENABLE_TEST_LOGIN=true
NEXT_PUBLIC_TEST_ACCOUNT_DOMAIN=restaurantbook.local
NEXT_PUBLIC_TEST_ACCOUNT_PASSWORD=password123
```

### 4-3. 개발 서버 실행

```bash
npm run dev
```

- 실행 포트: **4200**
- 브라우저: [http://localhost:4200](http://localhost:4200)

---

## 5. 전체 실행 순서 요약

```
1. docker compose up -d                         # DB 기동
2. application-local.yaml 생성 (최초 1회)
3. ./gradlew bootRun                            # 백엔드 (4201)
4. .env.local 생성 (최초 1회)
5. npm install && npm run dev                   # 프론트엔드 (4200)
```

## 7. 자주 발생하는 문제

### DB 연결 실패

```
원인: Docker 컨테이너가 아직 기동 중이거나 포트 5435 충돌
해결: docker compose ps 로 상태 확인 후 재기동
```

### `application-local.yaml` 없음 경고

```
원인: 파일이 .gitignore에 포함되어 있어 저장소에 없음
해결: 3-1 단계에서 example 파일을 복사해 생성
```

### `MAIL_USERNAME` 관련 오류

```
원인: 이메일 발송 설정 누락
해결: application-local.yaml에서 log-only: true 로 설정하면 이메일 없이 개발 가능
     로그에서 인증코드 확인 또는 dev-bypass-code(1234) 사용
```

### 프론트 API 호출 실패 (CORS / 404)

```
원인: .env.local 의 NEXT_PUBLIC_API_URL이 잘못 설정됨
해결: 백엔드가 4201 포트로 뜨고 있는지 확인 후 URL 맞게 수정
```
