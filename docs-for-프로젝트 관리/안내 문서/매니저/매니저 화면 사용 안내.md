# 매니저 화면 사용 안내

대상: 매장 매니저, 현장 책임자

## 매니저 화면은 무엇을 하는 화면인가?

매니저 화면은 매장 운영 현황을 한눈에 보고, 필요한 운영 화면으로 바로 이동하는 대시보드다.

매니저는 주문 흐름, 오늘 매출, 결제 대기, 결제 완료, 미처리 직원 호출을 확인하고 직원/주방 업무를 백업할 수 있다.

접속 화면:

- 매니저 대시보드: `/manager`

## 매니저가 확인할 핵심 지표

| 지표 | 의미 |
| --- | --- |
| 오늘 주문 | 오늘 접수된 주문 수 |
| 오늘 매출 | 결제 완료 기준 매출 |
| 결제 대기 | 조리 완료 후 아직 결제되지 않은 주문 |
| 결제 완료 | 결제가 끝난 주문 |
| 미처리 호출 | 고객이 보낸 직원 호출 중 아직 처리되지 않은 건 |

## 기본 사용 순서

1. 대시보드 확인
   - 영업 중에는 매니저 대시보드에서 전체 흐름을 먼저 본다.
   - 결제 대기나 호출 건수가 쌓이면 해당 화면으로 이동한다.

2. 직원 보드 확인
   - 결제 대기 주문과 직원 호출 처리를 확인한다.
   - 직원이 바쁠 때 매니저가 직접 결제/호출 처리를 백업할 수 있다.

3. 주방 현황 확인
   - 주문이 밀리는지, 조리 완료가 늦어지는지 확인한다.
   - 필요한 경우 주방과 홀 사이의 우선순위를 조정한다.

4. 매출 통계 확인
   - 오늘 매출, 결제수단별 매출, 환불 금액을 확인한다.
   - 특정 기간 매출도 조회할 수 있다.

5. 품절/노출 관리
   - 운영 중 품절 메뉴가 생기면 즉시 숨기거나 품절 처리한다.
   - 고객 키오스크에 노출되는 메뉴를 관리한다.

## 매니저가 자주 쓰는 바로가기

- 직원 주문 보드: `/staff`
- 주방 현황: `/kitchen-board`
- 매출 통계: `/sales`
- 품절/노출 관리: `/sale-menu-availability`
- 키오스크 보기: `/customer`

## 매니저에게 안내할 말

- “대시보드는 오늘 영업 상태를 보는 첫 화면입니다.”
- “미처리 호출이 쌓이면 직원 보드로 이동해 처리 상태를 확인하세요.”
- “품절 메뉴는 바로 숨겨야 고객 주문 실수를 줄일 수 있습니다.”
- “매출은 결제 완료와 환불 기록 기준으로 확인합니다.”

## 주의사항

- 매니저는 현장 운영 백업 권한이 넓게 열려 있다.
- 환불은 금전 처리이므로 매장 정책에 따라 확인 후 처리한다.
- 주방 상태를 직접 바꾸는 경우 실제 조리 상황과 맞는지 확인한다.
- 메뉴 노출/품절 변경은 고객 키오스크에 영향을 준다.
