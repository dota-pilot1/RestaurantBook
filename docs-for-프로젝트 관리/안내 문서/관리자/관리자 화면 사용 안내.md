# 관리자 화면 사용 안내

대상: 사장님, 시스템 관리자

## 관리자 화면은 무엇을 하는 화면인가?

관리자 화면은 RestaurantBook의 전체 설정과 운영 데이터를 관리하는 화면이다.

관리자는 사용자, 역할, 권한, 메뉴, 테이블, 내비게이션, 사이트 설정, 운영 일정 등을 관리한다. 매장 운영자가 직접 바꾸면 안 되는 구조적 설정은 관리자 화면에서 처리한다.

접속 화면 예시:

- 관리자 대시보드: `/dashboard`
- 판매 메뉴 관리: `/sale-menus`
- 카테고리 관리: `/sale-menu-categories`
- 테이블 관리: `/tables`
- 일정 관리: `/admin/calendar`
- 매출 통계: `/sales`
- 사용자 관리: `/users`
- 역할/권한 관리: `/roles`, `/permissions`
- 사이트 설정: `/site-settings`
- 화면 설정: `/screen-settings`

## 관리자가 주로 하는 일

### 1. 메뉴 관리

관리자는 판매 메뉴를 등록하고 수정한다.

가능한 작업:

- 메뉴명, 설명, 가격 수정
- 대표 이미지 등록
- 판매 상태 변경
- 품절/숨김 처리
- 매장 주문 가능 여부 설정
- 포장 주문 가능 여부 설정
- 조리 필요 여부 설정
- 카테고리별 메뉴 순서 조절

### 2. 카테고리 관리

고객 키오스크의 메뉴 카테고리 순서를 관리한다.

예:

```text
식사 → 국/찌개 → 면/분식 → 사이드 → 음료 → 세트 → 전체 보기
```

카테고리 순서는 고객 키오스크의 `전체 보기` 섹션 순서에도 영향을 준다.

### 3. 테이블 관리

매장에서 사용하는 테이블명을 관리한다.

예:

- 1번 테이블
- 2번 테이블
- 홀 A
- 포장 대기

테이블명은 고객 주문, 직원 호출, 매출/주문 확인에서 기준 정보로 사용된다.

### 4. 운영 일정 관리

관리자는 휴무, 이벤트, 메모 같은 운영 일정을 등록할 수 있다.

일정 타입:

- 공지
- 휴무
- 이벤트
- 메모

접속 화면:

- `/admin/calendar`

### 5. 사용자/권한 관리

사용자와 역할을 관리한다.

주요 역할:

| 역할 | 의미 |
| --- | --- |
| 관리자 | 전체 설정과 시스템 관리 |
| 매니저 | 매장 운영 관리 |
| 직원 | 홀/결제/호출 응대 |
| 주방 | 조리 상태 처리 |
| 고객 | 키오스크 주문 |

## 관리자에게 안내할 말

- “관리자 화면은 매장 운영 기준을 설정하는 곳입니다.”
- “메뉴 노출, 카테고리 순서, 테이블 정보는 고객 화면에 바로 영향을 줍니다.”
- “사용자와 권한은 직원별 업무 범위를 정하는 기능입니다.”
- “일정 관리는 휴무, 이벤트, 운영 메모를 한곳에 모아두는 기능입니다.”

## 주의사항

- 메뉴 삭제나 숨김은 고객 주문 가능 여부에 영향을 준다.
- 카테고리 순서를 바꾸면 고객 키오스크 메뉴 순서도 바뀐다.
- 권한을 잘못 변경하면 직원이 필요한 화면에 접근하지 못할 수 있다.
- 사이트/화면 설정은 전체 사용자 경험에 영향을 주므로 변경 전 확인한다.
