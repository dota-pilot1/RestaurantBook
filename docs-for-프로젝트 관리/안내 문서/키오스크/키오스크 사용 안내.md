# 키오스크 사용 안내

대상: 고객, 매장 직원 교육용

## 키오스크는 무엇을 하는 화면인가?

키오스크는 고객이 테이블에서 직접 메뉴를 고르고 주문을 접수하는 화면이다.

고객은 메뉴를 선택하고 주문을 접수한 뒤, 조리가 완료된 주문은 결제 버튼으로 후불 결제할 수 있다. 필요한 경우 직원 호출 버튼으로 물, 냅킨, 결제 도움 같은 요청도 보낼 수 있다.

접속 화면:

- 고객 키오스크: `/customer`
- 모바일 키오스크: `/customer/mobile`

## 기본 사용 순서

1. 테이블 확인
   - 화면 상단에 현재 테이블명이 표시된다.
   - 예: `3번 테이블`
   - 테이블이 맞지 않으면 직원에게 문의한다.

2. 매장/포장 선택
   - `매장`: 테이블에서 먹는 주문
   - `포장`: 가져가는 주문
   - 주문 유형에 따라 표시되는 메뉴가 달라질 수 있다.

3. 메뉴 선택
   - 카테고리 버튼을 눌러 메뉴를 확인한다.
   - `전체 보기`에서는 카테고리별로 묶인 전체 메뉴를 볼 수 있다.
   - 메뉴 카드의 `+` 버튼을 눌러 수량을 추가한다.
   - 이미 선택한 메뉴는 카드에 선택 표시가 나온다.

4. 주문 접수
   - 우측 주문 내역에서 선택한 메뉴와 금액을 확인한다.
   - `주문 접수하기`를 누르면 주방으로 주문이 전달된다.
   - 주문 접수 후에는 주방/직원 화면에 실시간으로 반영된다.

5. 결제
   - 주방에서 조리 완료 처리된 주문은 `결제` 버튼으로 결제할 수 있다.
   - 결제는 단건 결제 또는 여러 주문 묶음 결제로 진행할 수 있다.
   - 토스 테스트 결제창에서 결제가 완료되면 주문 상태가 `결제 완료`로 바뀐다.

6. 직원 호출
   - `직원 호출` 버튼으로 직원을 부를 수 있다.
   - 기본 요청 예시: 물, 냅킨, 앞접시, 그릇 치워주세요
   - 직접 메시지도 함께 입력할 수 있다.

## 고객에게 안내할 때 사용할 말

- “메뉴를 고르신 뒤 오른쪽 주문 내역에서 금액을 확인하고 주문 접수 버튼을 눌러주세요.”
- “조리 완료된 주문은 결제 버튼이 활성화됩니다.”
- “도움이 필요하시면 직원 호출 버튼을 눌러주세요.”
- “접수된 주문을 취소하려면 가능한 상태에서는 화면에서 취소할 수 있고, 접수 이후에는 직원에게 말씀해주세요.”

## 주의사항

- 품절 메뉴는 선택할 수 없다.
- 장바구니에 아직 접수하지 않은 메뉴가 있으면 결제보다 주문 접수를 먼저 해야 한다.
- 결제 버튼은 조리 완료/결제 대기 주문이 있을 때만 활성화된다.
- 같은 테이블에서 너무 짧은 시간 안에 중복 직원 호출을 하면 제한될 수 있다.

## 시연 체크리스트

- [ ] 테이블명이 맞게 표시되는지 확인
- [ ] 매장/포장 전환 확인
- [ ] 카테고리별 메뉴 조회 확인
- [ ] `전체 보기`에서 카테고리별 섹션 확인
- [ ] 메뉴 선택 후 주문 내역 수량/금액 확인
- [ ] 주문 접수 확인
- [ ] 직원 호출 생성 확인
- [ ] 조리 완료 후 결제 버튼 활성화 확인
