# 직원 화면 사용 안내

대상: 홀 직원, 결제 담당자

## 직원 화면은 무엇을 하는 화면인가?

직원 화면은 홀 운영자가 주문 상태를 확인하고 결제 완료, 환불, 직원 호출 응대를 처리하는 화면이다.

주방에서 조리 완료된 주문은 직원 화면에서 결제 대기 상태로 확인할 수 있다. 고객이 키오스크에서 직원 호출을 하면 직원 화면에 알림으로 표시된다.

접속 화면:

- 직원 주문 보드: `/staff`

## 직원이 주로 보는 정보

- 테이블별 주문 상태
- 조리 완료/결제 대기 주문
- 결제 완료 주문
- 직원 호출 알림
- 주문 취소 알림
- 환불 처리 버튼

## 기본 사용 순서

1. 결제 대기 주문 확인
   - 주방에서 `조리 완료` 처리한 주문이 직원 화면에 표시된다.
   - 테이블명, 주문번호, 메뉴, 금액을 확인한다.

2. 결제 완료 처리
   - 고객이 현장 결제를 하면 결제수단을 선택한다.
   - 카드, 현금, 기타 결제수단을 기록할 수 있다.
   - 결제 완료 처리 후 주문은 완료 상태가 된다.

3. 고객 토스 결제 확인
   - 고객이 키오스크에서 토스 결제를 완료하면 결제수단 배지가 표시된다.
   - 예: 카드, 간편결제, 카카오페이, 토스페이 등

4. 직원 호출 응대
   - 직원 호출 알림이 있으면 호출 내용을 확인한다.
   - 테이블, 메시지, 경과시간을 보고 응대한다.
   - 응대 후 `처리 완료`로 변경한다.

5. 환불 처리
   - 결제 완료 주문에 환불 버튼이 표시된다.
   - 환불은 금액 처리이므로 매장 정책에 따라 매니저 확인 후 진행한다.

## 직원 호출 예시

고객이 보낼 수 있는 요청:

- 물
- 냅킨
- 앞접시
- 그릇 치워주세요
- 메뉴 문의
- 결제 도움
- 기타 직접 입력 메시지

## 직원에게 안내할 말

- “조리 완료 주문은 결제 대기 주문으로 확인하세요.”
- “현장 결제는 결제수단을 선택하고 완료 처리하면 됩니다.”
- “고객 호출은 알림에서 테이블과 메시지를 확인한 뒤 처리 완료해주세요.”
- “환불은 매장 책임자 확인 후 처리해주세요.”

## 주의사항

- 결제 완료 처리 후 주문은 고객 active 주문 목록에서 빠진다.
- 같은 주문을 중복 결제하지 않도록 주문번호와 금액을 확인한다.
- 환불 처리 후 매출 화면에 환불 금액이 반영된다.
- 직원 호출을 처리 완료하면 고객 화면에서도 호출 상태가 종료된다.

## 시연 체크리스트

- [ ] 조리 완료 주문이 직원 화면에 표시되는지 확인
- [ ] 카드/현금/기타 결제 완료 처리 확인
- [ ] 결제 완료 후 주문 상태 변경 확인
- [ ] 고객 직원 호출 알림 확인
- [ ] 직원 호출 처리 완료 확인
- [ ] 결제 완료 주문 환불 처리 확인
