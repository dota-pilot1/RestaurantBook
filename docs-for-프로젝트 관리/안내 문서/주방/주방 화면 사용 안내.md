# 주방 화면 사용 안내

대상: 주방 담당자

## 주방 화면은 무엇을 하는 화면인가?

주방 화면은 고객이 접수한 주문을 확인하고 조리 상태를 변경하는 화면이다.

주방 담당자는 주문을 접수하고, 조리를 시작하고, 조리가 끝나면 준비 완료로 바꾼다. 조리 상태가 바뀌면 직원 화면과 고객 화면에도 반영된다.

접속 화면:

- 주방 현황: `/kitchen-board`

## 주문 상태 흐름

주방에서 주로 다루는 상태는 아래 순서다.

```text
주문 접수 대기(RECEIVED)
→ 주문 접수 완료(ACCEPTED)
→ 조리 중(COOKING)
→ 조리 완료/결제 대기(READY)
```

상태 의미:

| 상태 | 의미 | 주방에서 할 일 |
| --- | --- | --- |
| 주문 접수 대기 | 고객 주문이 들어온 상태 | 주문 내용을 확인하고 접수 |
| 주문 접수 완료 | 주방이 주문을 받은 상태 | 조리 시작 준비 |
| 조리 중 | 실제 조리 중 | 조리 완료 시 다음 상태로 변경 |
| 조리 완료/결제 대기 | 음식 준비 완료 | 직원/고객 결제 단계로 넘어감 |

## 기본 사용 순서

1. 새 주문 확인
   - 새 주문은 `주문 접수 대기` 영역에 표시된다.
   - 테이블명, 주문번호, 메뉴, 수량을 확인한다.

2. 주문 접수
   - 주문을 확인했으면 접수 처리한다.
   - 접수 후 주문은 `주문 접수 완료` 상태로 이동한다.

3. 조리 시작
   - 조리에 들어가면 `조리 중`으로 변경한다.
   - 직원과 매니저가 현재 조리 상황을 확인할 수 있다.

4. 조리 완료
   - 음식이 나갈 준비가 되면 `조리 완료`로 변경한다.
   - 이 상태가 되면 고객/직원 결제 흐름으로 넘어갈 수 있다.

5. 주방 취소
   - 재료 부족, 주문 불가 등 조리 단계에서 처리할 수 없는 주문은 취소 처리한다.
   - 취소 사유는 고객 화면에 안내될 수 있으므로 짧고 명확하게 작성한다.

## 조리 불필요 메뉴

음료처럼 조리가 필요 없는 메뉴는 접수 시 바로 `조리 완료/결제 대기`로 넘어갈 수 있다.

예:

- 콜라
- 식혜
- 수정과

관리자가 메뉴 관리에서 `조리 필요` 여부를 설정한다.

## 주방 담당자에게 안내할 말

- “새 주문은 먼저 접수 처리해주세요.”
- “조리를 시작하면 조리 중으로 바꾸고, 음식이 준비되면 조리 완료로 바꿔주세요.”
- “주문을 처리할 수 없으면 취소 사유를 남겨주세요.”
- “결제 처리는 주방 화면에서 하지 않습니다.”

## 주의사항

- 주문 상태를 바꾸면 고객/직원 화면에 반영된다.
- 잘못 `조리 완료` 처리하면 고객 결제 버튼이 활성화될 수 있다.
- 주방은 결제 완료 처리를 하지 않는다.
- 주문 취소는 고객에게 보일 수 있으므로 사유를 정확히 작성한다.

## 시연 체크리스트

- [ ] 새 주문이 주방 화면에 표시되는지 확인
- [ ] 주문 접수 처리 확인
- [ ] 조리 중 변경 확인
- [ ] 조리 완료 변경 확인
- [ ] 조리 완료 후 직원/고객 화면 반영 확인
- [ ] 조리 불필요 메뉴가 바로 준비 완료로 가는지 확인
