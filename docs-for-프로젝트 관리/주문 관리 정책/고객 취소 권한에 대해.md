# 고객 취소 권한에 대해

## 현재 정책

고객 화면에서 직접 주문 취소는 `주문 접수 대기(RECEIVED)` 상태에서만 허용한다.

주방 또는 직원이 주문을 접수한 뒤에는 고객이 직접 취소하지 못한다.

- `RECEIVED`: 고객 직접 취소 가능
- `ACCEPTED`: 고객 직접 취소 불가, 직원 문의
- `COOKING`: 고객 직접 취소 불가, 직원 문의
- `READY`: 고객 직접 취소 불가, 직원 문의
- `COMPLETED`: 고객 직접 취소 불가
- `CANCELED`: 이미 취소된 주문

## 이유

`ACCEPTED` 이후에는 매장 운영자가 주문을 확인했거나 조리가 시작된 상태다.
이 구간에서 고객이 임의로 취소하면 재고, 조리, 결제 대기 흐름이 꼬일 수 있다.

그래서 고객 직접 취소는 접수 전까지만 허용하고, 이후 취소는 주방 또는 직원 화면에서 처리한다.

## 현재 화면 동작

고객 페이지 주문 내역에서는 모든 활성 주문에 취소 버튼 자리를 보여준다.

- `RECEIVED` 주문: `주문 취소` 버튼 활성화
- `ACCEPTED` 이후 주문: 버튼 비활성화, `접수 후 취소는 직원 문의` 표시

백엔드도 같은 정책을 적용한다.
프론트 버튼을 우회해서 API를 직접 호출해도 `RECEIVED`가 아니면 취소되지 않는다.
