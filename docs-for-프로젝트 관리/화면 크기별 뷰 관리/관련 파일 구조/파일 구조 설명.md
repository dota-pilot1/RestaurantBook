# 화면 크기별 뷰 관련 파일 구조

작성일: 2026-05-10

## 핵심 구조

고객 키오스크는 화면 크기에 따라 라우트와 `variant`로 뷰를 나눈다.

```text
restaurant-book-front/src/app/customer/
  page.tsx
  mobile/page.tsx

restaurant-book-front/src/features/kiosk/
  KioskHome.tsx
  model/
    useKioskOrder.ts
    useMobileProductPager.ts
  ui/
    KioskDesktopView.tsx
    KioskMobileView.tsx
    KioskDialogs.tsx
```

## 라우트 분기

| 파일 | 역할 |
| --- | --- |
| `src/app/customer/page.tsx` | 기본 고객 키오스크 라우트. `max-width: 767px`이면 `/customer/mobile`로 이동한다. |
| `src/app/customer/mobile/page.tsx` | 모바일 전용 라우트. `KioskHome variant="mobile"`을 렌더링한다. |

## 뷰 선택

| 파일 | 역할 |
| --- | --- |
| `src/features/kiosk/KioskHome.tsx` | `useKioskOrder()`를 호출하고 `variant`에 따라 모바일/데스크톱 뷰를 선택한다. |
| `src/features/kiosk/ui/KioskDesktopView.tsx` | 태블릿/노트북/데스크톱용 키오스크 화면. Tailwind `sm`, `lg`, `xl` 기준으로 내부 레이아웃이 바뀐다. |
| `src/features/kiosk/ui/KioskMobileView.tsx` | 모바일용 키오스크 화면. 한 장씩 넘기는 메뉴 카드와 하단 fixed 주문 영역을 사용한다. |
| `src/features/kiosk/ui/KioskDialogs.tsx` | 모바일 화면에서 사용하는 주문/결제/직원 호출/설정 다이얼로그 묶음. |

## 상태 모델

| 파일 | 역할 |
| --- | --- |
| `src/features/kiosk/model/useKioskOrder.ts` | 주문, 장바구니, 결제, 직원 호출, 설정, WebSocket 상태를 조립하는 키오스크 주 상태 모델. |
| `src/features/kiosk/model/useMobileProductPager.ts` | 모바일 메뉴 카드 index, slide 방향, touch swipe 상태를 관리한다. |

## 기준 요약

- `767px 이하`: `/customer/mobile` → `KioskMobileView`
- `768px 이상`: `/customer` → `KioskDesktopView`
- `1024px 이상`: `KioskDesktopView` 내부에서 주문 내역 사이드바가 붙는 2단 구조
- `1280px 이상`: 메뉴 카드 grid가 더 넓은 데스크톱형으로 확장

즉 실제 화면 크기 판단의 시작점은 `src/app/customer/page.tsx`이고, 최종 화면 선택은 `src/features/kiosk/KioskHome.tsx`에서 처리한다.
