# 판매 메뉴 선택시 카드 우상단에 체크 마크 출력

작성일: 2026-05-08

## 목적

키오스크 메뉴 선택 시 선택 상태를 직관적으로 표현하기 위해
카드 우상단 모서리 밖으로 체크 마크 배지를 오버레이.

기존 테두리(border-zinc-900) + ring 표현에서 시각적 명확성 강화.

## 변경 파일

`restaurant-book-front/src/features/kiosk/KioskHome.tsx`

## 변경 내용

### 1. lucide-react에 Check 아이콘 추가

```tsx
import {
  Check,   // ← 추가
  XCircle,
  ImageIcon,
  ...
} from "lucide-react";
```

### 2. MenuCard return 구조 변경

`<article>`을 `<div className="relative">`로 감싸고,
체크 배지를 article 바깥(형제 요소)으로 위치시킴.

`<article>`이 `overflow-hidden`을 갖고 있어서
내부에서 `-top`, `-right` 음수값을 쓰면 클리핑됨.
래퍼 div를 사용해야 카드 밖으로 튀어나오는 효과를 낼 수 있음.

```tsx
return (
  <div className="relative">
    {quantity > 0 && (
      <div className="absolute -right-2.5 -top-2.5 z-30 flex h-6 w-6 items-center justify-center rounded-full bg-zinc-900 shadow-md">
        <Check className="h-3.5 w-3.5 text-white" strokeWidth={3} />
      </div>
    )}
    <article ...>
      {/* 기존 내용 유지 */}
    </article>
  </div>
);
```

## 스타일 결정 근거

| 항목 | 값 | 이유 |
|------|-----|------|
| 위치 | `-right-2.5 -top-2.5` | 카드 모서리 밖으로 살짝 튀어나옴 |
| 크기 | `h-6 w-6` (24px) | 너무 크면 카드 느낌 깨짐, 너무 작으면 안 보임 |
| 색상 | `bg-zinc-900` | 선택 테두리 색과 동일 → 일관성 |
| z-index | `z-30` | ring overlay(z-20)보다 위에 렌더링 |
| strokeWidth | `3` | 작은 크기에서도 체크 모양 선명하게 |
| shadow | `shadow-md` | 배경 이미지 위에서 구분감 확보 |

## 조건

`quantity > 0` 일 때만 체크 배지 렌더링.
수량이 0으로 돌아오면 자동 제거.
