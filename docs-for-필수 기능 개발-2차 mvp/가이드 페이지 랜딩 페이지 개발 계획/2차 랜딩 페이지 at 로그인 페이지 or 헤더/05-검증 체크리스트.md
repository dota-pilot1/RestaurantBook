## 콘텐츠 정합성 (실제 구현 기준)

[1차 mvp 구현 현황](../../../docs-for-프로젝트%20관리/구현%20현황/1차%20mvp%20구현%20현황.md), [2차 mvp 구현 현황](../../../docs-for-프로젝트%20관리/구현%20현황/2차%20mvp%20구현%20현황.md)과 1:1 대조.

- [ ] "실시간 갱신 / WebSocket" 카피 — 1차 1.5절 WebSocket 전파와 일치
- [ ] "직원 호출 (수저/물/계산)" 카피 — 2차 1.7절 / `고객의 직원 호출 기능 구현` 문서와 일치
- [ ] "조리 불필요 메뉴 자동 준비 완료" 카피 — 2차 1.3절과 일치
- [ ] "결제수단별 매출 + 환불 분리" 카피 — 1차 매출 관리 + 2차 1.5절 환불 집계와 일치
- [ ] "역할 / 권한 관리" 카피 — 기존 관리자 화면(roles, permissions, role-permissions)과 일치
- [ ] "4개 언어" 카피 — `SUPPORTED_LANGUAGES` (ko/en/ja/zh)와 일치
- [ ] 랜딩에 등장하지 않은 기능 약속(예: PG 자동 환불, 영수증 출력)이 카피에 섞여 있지 않음

## i18n

- [ ] ko: 모든 섹션 한국어 정상
- [ ] en: 의역된 영어 (직역 X)
- [ ] ja/zh: ko 폴백, missing key 경고만
- [ ] 4개 언어 전환 시 `landing.*` 키가 그대로 노출되지 않음
- [ ] hero의 한국어 줄바꿈이 영어 전환 시 어색하지 않음

## SEO / 메타

- [ ] 루트 페이지 `<title>`, `<meta name="description">` 정상
- [ ] OG 태그(`og:title`, `og:description`, `og:image`) 정상
- [ ] `/og.png` 1200×630 자리에 실제 이미지 존재
- [ ] `<html lang>`이 현재 언어와 일치
- [ ] `robots.txt`에서 `/login`, `/register`, `/dashboard` 등 비공개 라우트 disallow (선택)

## 반응형 / 테마

- [ ] 데스크톱(≥1280): hero 좌측 텍스트 / 우측 이미지 2열
- [ ] 태블릿(1024–1279): hero 2열 유지 또는 자연스럽게 1열 전환
- [ ] 모바일(<768): hero 1열 (텍스트 위, 이미지 아래)
- [ ] ScreensPreview 3-up — 모바일은 1열, 태블릿은 1~2열, 데스크톱은 3열
- [ ] 다크/라이트 양쪽 가독성 OK
- [ ] hero 이미지 LCP 시간 측정(Chrome DevTools) — 2.5s 이내
