# 04. i18n 콘텐츠 카피

## 목표

가이드 전용 네임스페이스 `guide`를 추가하고, 한국어/영어를 1차 콘텐츠로 굳힌다. 일본어/중국어는 같은 키를 등록만 하고 한국어 폴백을 허용한다.

## 1. 네임스페이스 등록

[src/shared/i18n/index.ts](../../../../restaurant-book-front/src/shared/i18n/index.ts)의 `ns` 배열에 `guide` 추가.

```ts
ns: ["common", "nav", "auth", "form", "guide"],
```

각 언어 리소스 인덱스([resources/{ko,en,ja,zh}/index.ts](../../../../restaurant-book-front/src/shared/i18n/resources))에서도 `guide` 객체 export 추가.

```ts
import { guide } from "./guide";
export const ko = { common, nav, auth, form, guide };
```

## 2. 파일 구조

```
src/shared/i18n/resources/
├── ko/
│   ├── guide.ts        # 한국어 (1차 정본)
│   └── nav.ts          # 기존 + guide 키 추가
├── en/
│   ├── guide.ts        # 영어 (1차 필수)
│   └── nav.ts
├── ja/
│   ├── guide.ts        # 일본어 (1차는 ko 폴백, 키만 등록)
│   └── nav.ts
└── zh/
    ├── guide.ts        # 중국어 (1차는 ko 폴백, 키만 등록)
    └── nav.ts
```

## 4. 영어 카피 (en/guide.ts)

핵심 키만 표 — 그대로 옮기지 말고 영어식으로 다듬는다.

| 키 | 영어 |
| --- | --- |
| `hero.title` | How an order flows through your store |
| `hero.subtitle` | See how a customer's order moves from kitchen to checkout |
| `flow.customer` | Customer order |
| `flow.kitchen` | Kitchen prep |
| `flow.staff` | Staff serving |
| `flow.complete` | Paid |
| `cards.yourRoleBadge` | Your role |
| `cards.detailLink` | Learn more |
| `cards.customer.title` | Customer |
| `cards.customer.desc` | Order from the kiosk and call staff |
| `cards.kitchen.title` | Kitchen |
| `cards.kitchen.desc` | Accept orders and update cooking status |
| `cards.staff.title` | Staff |
| `cards.staff.desc` | Take payments and respond to calls |
| `admin.summary` | Where are the admin menus? |
| `switcher.title` | See other roles |

상세 페이지 단계/상황 카피는 한국어 카피를 영어식으로 자연스럽게 옮긴다 (불필요한 직역 금지).

## 5. 일본어/중국어

1차에서는:

```ts
// ja/guide.ts
import { guide as ko } from "../ko/guide";
export const guide = ko; // 의도적 폴백, TODO 주석 추가
```

또는 i18next의 `fallbackLng: "ko"`를 가이드 네임스페이스에서만 적용하고 빈 객체 export.

**권장**: 빈 객체로 두고 `fallbackLng`에 의존. 프로덕션 번역 들어오는 시점에 채운다.

```ts
// ja/guide.ts
export const guide = {}; // TODO: i18n - guide ja translation
```

## 7. 검증

- 4개 언어 전환 시 `/guide` 메인의 hero/flow/cards가 모두 번역됨 (한국어/영어).
- ja/zh로 전환 시 한국어 폴백이 자연스럽게 노출되고 콘솔에 i18next 경고만 발생, 화면 빈칸 없음.
- `t("guide.cards.staff.step3")` 같은 키가 화면에 그대로 노출되는 곳이 없음 (개발 모드 missing key 검사).
