# 05. 검증 체크리스트

작성일: 2026-05-08

## 빌드/품질 게이트

- [ ] `cd restaurant-book-front && npm run lint`
- [ ] `cd restaurant-book-front && npm run build`
- [ ] `git diff --check`

## 라우팅

- [ ] 헤더 "사용 가이드" 클릭 → `/guide` 진입
- [ ] `/guide` 메인의 역할 카드 클릭 → 해당 상세로 진입
- [ ] hero 플로우의 노드(고객/주방/직원) 클릭 → 해당 상세로 진입
- [ ] 상세 페이지 하단 RoleSwitcher로 다른 두 역할로 이동
- [ ] 상세 페이지에서 브라우저 뒤로가기 → 메인으로 복귀
- [ ] `/guide`, `/guide/customer`, `/guide/kitchen`, `/guide/staff`를 새 탭에서 직접 열어도 정상 렌더 (직링크)

## 권한·노출

- [ ] 비로그인 상태: 헤더에 "사용 가이드" 안 보임
- [ ] 비로그인 상태: `/guide` 직접 접근 → `/login?next=/guide`로 리다이렉트
- [ ] 로그인 후 `/login?next=/guide` → `/guide`로 자동 진입
- [ ] ROLE_CUSTOMER 로그인: 헤더에 "사용 가이드" 노출, 메인 진입 가능
- [ ] ROLE_KITCHEN/ROLE_STAFF/ROLE_MANAGER/ROLE_ADMIN 모두 노출
- [ ] 본인 역할 카드에 "내 역할" 뱃지 표시 (해당하는 사용자에게만)

## 메뉴 데이터 정합성

- [ ] `navigation_menus` 테이블에 GUIDE row가 없을 때도 헤더에 보임 (`fallbackNavigationMenus` 동작)
- [ ] `navigation_menus` 테이블에 GUIDE row를 추가했을 때 라벨이 DB 우선으로 노출
- [ ] `displayOrder`가 다른 메뉴 뒤에 위치 (관리자 그룹 다음)
- [ ] 관리자 메뉴 접힘 영역의 링크들이 모두 유효 (404 없음)

## i18n

- [ ] ko: hero/flow/cards/관리자 요약/상세 페이지 모두 한국어 노출
- [ ] en: 한국어 카피의 영어 의역 노출 (직역 X)
- [ ] ja: 키 누락 시 ko 폴백, missing key 경고만 콘솔에
- [ ] zh: 위와 동일
- [ ] 4개 언어 전환 후 새로고침해도 선택 언어 유지 (`LANGUAGE_STORAGE_KEY`)
- [ ] 키가 그대로 노출된 텍스트 없음 (예: `guide.cards.staff.step3`)

## 반응형 / 테마

- [ ] 데스크톱(≥1280): 카드 3열, hero 가로 플로우
- [ ] 태블릿(1024–1279): 카드 3열 유지
- [ ] 모바일(<768): 카드 1열, hero 세로 플로우, 화살표 ↓
- [ ] 다크/라이트 둘 다 카드 accent 컬러 가독성 OK
- [ ] 스크린샷이 컨테이너 밖으로 넘치지 않음

## 콘텐츠 정합성 (실제 구현과 일치)

- [ ] 주문 상태 전이 표기: `RECEIVED → ACCEPTED → COOKING → READY → COMPLETED`
- [ ] 결제수단 표기: `CARD / CASH / ETC`
- [ ] 환불 전이: `Order COMPLETED → CANCELED`, `Payment PAID → REFUNDED`
- [ ] 조리 불필요 메뉴 자동 READY 동작 설명이 [2차 mvp 구현 현황](../../../docs-for-프로젝트%20관리/구현%20현황/2차%20mvp%20구현%20현황.md) 1.3 절과 일치
- [ ] 직원 호출 1분 내 중복 차단 설명이 [2차 mvp 구현 현황](../../../docs-for-프로젝트%20관리/구현%20현황/2차%20mvp%20구현%20현황.md) 1.7 절과 일치
